# Summarize a selectiveHotelling object

Summarize a selectiveHotelling object

``` r
# S3 method for class 'selectiveHotelling'

```

## Arguments

- object:

  A `"selectiveHotelling"` object from

- ...:

  Ignored.

## Value

`object`, invisibly (after printing a summary).
